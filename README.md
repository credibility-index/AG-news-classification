# AG News Text Classification with TextCNN (NLP)

## 🧠 Задача курса NLP
1. Реализовать **задачу классификации текстов** (multi‑class text classification) на примере новостных заголовков и кратких описаний.
2. Проанализировать:
  - влияние размера словаря и длины последовательности,  
  - поведение свёрточной модели на тексте (TextCNN) по сравнению с классическими ML‑подходами.  
3. Цель по качеству: достичь макро‑F1 ≥0.95 на тестовой выборке.

## 📦 Данные

Используется датасет **AG News** (4 класса, 120k train, 7.6k test):
## Классы: ##
  - `0` — World  
  - `1` — Sports  
  - `2` — Business  
  - `3` — Sci/Tech  ## Формат:
  - `label` — номер класса (1–4),
  - `title` — заголовок,
  - `text` — краткий текст статьи.

Датасет автоматически скачивается через `kagglehub.dataset_download` и хранится в локальном кэше.

## Предобработка текста (NLP‑часть)

1. **Объединение заголовка и текста**  
 Каждый пример: `text = title + " " + text`, чтобы модель видела и заголовок, и тело.
2. **Токенизация**  
Текст приводится к нижнему регистру,  
Удаляются все символы, кроме букв и пробелов,  
Строка разбивается на слова длиной >1 символ.
3. **Словарь и обрезка**  
Строится частотный словарь топ‑10 000 слов по первым 3000 новостям.  
Специальные индексы:
- `0` — padding,
- `1` — OOV (слова вне словаря).  
- последовательность обрезается или дополняется до фиксированной длины `MAX_LEN = 200`.

## Модель: TextCNN

Архитектура **TextCNN** — классическая свёрточная модель для текстовой классификации:
1. `nn.Embedding(vocab_size, embed_dim=100)` — слой векторизации слов (word embeddings).  
2. Несколько одномерных свёрток `nn.Conv1d(embed_dim, 128, kernel_size=k)` для `k ∈ [2,3,4,5]`:
3. Извлекают n‑граммы разной длины (биграммы, триграммы и т.п.).  
4. После каждого свёрточного слоя происходит:
  а) `ReLU` активация,
  б) `adaptive_avg_pool1d(..., 1)` — усреднение до 1 скалярного признака.  
5. Конкатенация признаков всех свёрток → `nn.Linear(128*4, 4)` + `Dropout(0.3)` для регуляризации.

## Обучение и оценка

**Оптимизатор**: `Adam` с `lr=0.001`.  
**Функция потерь**: `CrossEntropyLoss`.  
**Batch size**: `128`.  
**Эпохи**: `3` (быстрое обучение, укладывается примерно в 10 минут на CPU).  
Разделение выборки:
  - Тренировочная часть: `train_df_split`,
  - Валидационная часть: `val_df` (10% от train).

## Оценка качества:
1. Точность и макро‑F1‑мера на валидации и тесте.
2. Построение **confusion matrix** по классам `['World','Sports','Business','Sci/Tech']` с анализом перепутанных категорий.
